    How a model gets approved

    From my MSc thesis in Global BIM Management: a simulation-based project run with open BIM standards from the outset, using agile and scrum. As project BIM Coordinator I worked with the BIM Manager to develop the BEP and Exchange Information Requirements, then validated every model in four steps.

    • EIR defined from the client perspective, passed through the project team to define the BEP
    • Level of Information Need used to control over-production of information
